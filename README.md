# Notes App

A full-stack notes application with rich text editing, real-time sync across
tabs, search, and export/import - built as part of the 10Pearls MERN
internship (Cohort 9).

## Features

- **Authentication**: signup/login with JWT access + refresh tokens,
  httpOnly refresh cookie, bcrypt-hashed passwords
- **Notes CRUD**:  create, edit, and delete notes with a rich text editor
  (bold, italic, headings, bullet lists)
- **Search**: find notes by title or content, debounced and backend-driven
- **Export / Import**:  download all notes as a JSON file, or import notes
  from a file
- **Real-time sync**:  note changes sync live across open tabs via
  Socket.IO, scoped per user
- **Form validation**:  email format and password requirements enforced on
  both the client and the server

## Tech stack

**Frontend**
- React + TypeScript + Vite
- React Router
- TanStack Query
- Tailwind CSS
- TipTap (rich text editor)
- Axios
- Socket.IO client

**Backend**
- Node.js + Express 5
- MongoDB + Mongoose
- Socket.IO
- JWT authentication, bcrypt
- Pino (logging)

**Testing**
- Backend: Mocha, Chai, Supertest, mongodb-memory-server
- Frontend: Jest, React Testing Library

**Code quality**
- SonarCloud (static analysis, CI-based)

## Getting started

### Prerequisites

- Node.js 20+
- A MongoDB instance (local or [MongoDB Atlas](https://www.mongodb.com/atlas))

### 1. Clone the repository

```bash
git clone https://github.com/AsadullahSamo/cohort-9-mern-13683-asadullah/
cd cohort-9-mern-13683-asadullah
```

### 2. Backend setup

```bash
cd server
npm install
```

Create a `.env` file in `server/` with the following variables:

```
PORT=5000
MONGODB_URI=your-mongodb-connection-string
JWT_ACCESS_SECRET=your-access-token-secret
JWT_REFRESH_SECRET=your-refresh-token-secret
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

Run the backend:

```bash
npm run dev
```

### 3. Frontend setup

```bash
cd client
npm install
```

Run the frontend:

```bash
npm run dev
```

The app will be available at `http://localhost:5173`, with API requests
proxied to the backend at `http://localhost:5000`.

## Deployment

The app is designed to deploy with the frontend and backend on separate
hosts (for example, [Vercel](https://vercel.com) for the frontend and
[Render](https://render.com) for the backend), backed by
[MongoDB Atlas](https://www.mongodb.com/atlas).

Required environment variables for a cross-origin deployment:

**Backend (Render)**
```
MONGO_URI, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET, CLIENT_URL, NODE_ENV=production
```

**Frontend (Vercel)**
```
VITE_API_BASE_URL   # e.g. https://your-backend.onrender.com/api
VITE_SOCKET_URL     # e.g. https://your-backend.onrender.com
```
